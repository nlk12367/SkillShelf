中文用途依 Skill 原文整理

找到 Skill，帶到 Codex 使用

  1. 說出想做的事

    輸入「做簡報」或「讓 3D 角色可以點選」，也能搜尋英文名稱。

  2. 確認中文用途

    點選結果，查看中文用途與完整 Skill 名稱。

  3. 複製到 Codex

    第一行是 /Skill 名稱，在「任務」寫下需求，也能加入多筆資源路徑。按「複製使用指令」，再貼到 Codex。

複製內容包含 /Skill 名稱、任務與選填的資源清單，不會自動執行。

以「開啟 SkillShelf.cmd」開啟可直接拖曳、貼上或選擇檔案。HTML 版仍可手動加入路徑；兩個版本都保留收藏與最近查看記錄。
